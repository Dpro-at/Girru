# Choose your contribution

Prefer an extension for a new independent executable capability. Core changes are appropriate for shared contracts, security fixes and foundations that cannot be implemented safely through existing extension points. Skills describe work; they do not create tool permissions.

| Contribution | Start here | Owning area |
|---|---|---|
| Reusable written workflow | [Skills](skills.md) | Skill source / Store skill item |
| Job role and workflow mapping | [Specialties](specialties.md) | Specialty library and source pack |
| Working style and traits | [Personalities](personalities.md) | Personality library |
| Executable integration or service | [Extensions](extensions.md) | Extension SDK and package |
| Discoverable downloadable item | [Store apps](store-apps.md) | Separate Store repository |
| Tool or MCP server | [Tools and MCP](tools-and-mcp.md) | Tool implementation and grants |
| Messaging connector | [Channels](channels.md) | Agent Connect and host adapter |
| 3D world authoring | [GenVR](genvr.md) | GenVR SDK and host integration |
| Localisation and RTL | [Translations](translations.md) | Active screen's text catalogue |
| Shared runtime, memory or UI | [Core](core.md) | Girru shared implementation |
| Memory import, recall and learned experience | [Memory](memory.md) | Girru memory boundaries |
| Avatars, speech or voice resources | [Avatars and voice](avatars-and-voice.md) | Media services and native host |
| Shipped content revision | [Content updates](content-updates.md) | Immutable source/update history |

Example: Video Editor is a specialty; shot planning is a skill; a rendering tool is executable capability; creativity is a personality trait. Tool grants are separate from all four.

Before editing, read [architecture boundaries](../architecture/overview.md), [workflow](agent-workflow.md) and [testing](testing.md). Package and repository links are in the [ecosystem map](../ecosystem/repositories.md).
